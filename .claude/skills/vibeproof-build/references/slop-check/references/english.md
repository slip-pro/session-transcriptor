# English editorial profile

Read alongside the shared workflow. Edit existing English, including English written by non-native speakers. Awkward English is a readability issue, not evidence of authorship.

## Locale and reader

Use the requested dialect or the publication's established style. Preserve a consistent existing variant; if none is evident, avoid unnecessary localisation and state a choice only when it affects the work. Do not impose British English globally.

British examples: organisation, prioritise, programme for a course, practise as a verb and practice as a noun. Computer program and product names keep their spelling. Preserve branded glossary capitalisation. American English is equally valid when it is the target.

An international business audience benefits from familiar words and explicit relationships. An expert audience may prefer concise technical language. Explain unfamiliar abbreviations once; do not explain CEO to a board or reintroduce context already shared in a reply.

## Structural markers

| Code | Look for | Editorial decision |
|---|---|---|
| EN-S1 | Unmotivated not-X-but-Y contrasts or imaginary objections | Remove the empty contrast; retain genuine alternatives, exclusions and corrections. |
| EN-S2 | Staged openers and punchy closing lines that repeat the point | Start or end with the useful statement. A short sentence with new information can stay. |
| EN-S3 | Every block has three examples, the same opening or a polished moral | Read the outline aloud; combine only redundant items. Preserve complete lists and intentional repetition. |
| EN-S4 | A difficulty is followed by reassurance with no supporting information | Preserve the limitation; do not invent its resolution. |
| EN-S5 | A factual sentence gains an unsupported interpretation or cause | Separate evidence from judgment. Preserve an attributed opinion as an opinion. |
| EN-S6 | Labels, bold, arrows and headings replace actual organisation | Retain useful scanning aids and site design; remove decoration only within authorised prose scope. |
| EN-S7 | Reply repeats the recipient's question and all prior reasoning | Lead with the answer and the information the reader still needs. |

## Sentence-level markers

| Code | Look for | Editorial decision |
|---|---|---|
| EN-L1 | Empty lead-ins, inflated importance, generic praise | Delete padding without deleting substantive claims. |
| EN-L2 | Noun stacks and nominalisations that hide actions | Identify the action and, if known, the actor. Do not invent ownership. |
| EN-L3 | Unnecessary long words | Prefer use to utilise when equivalent; retain precise technical senses. |
| EN-L4 | Repeated synonyms for one concept | Repeat the agreed term. Consistency is more useful than decorative variety. |
| EN-L5 | Several stacked qualifiers | Keep the uncertainty the source expresses; remove only redundant hedges. |
| EN-L6 | Missing referents, overloaded clauses, unclear parallel lists | Make relationships explicit, checking that the rewrite preserves them. |
| EN-L7 | Ceremonial chatbot commentary in standalone prose | Remove the wrapper. Ordinary courtesy in an actual email can remain. |

Words such as leverage, seamless, pivotal, robust and landscape warrant attention when vague or clustered. A robust statistical estimator, an actual landscape and a necessary transition are ordinary English. No word is an automatic ban.

## Naturalness and collocations

Code EN-N1 covers grammar, articles, prepositions, countability and agreement. Code EN-N2 covers literal translations and combinations an English-speaking editor would not choose. Code EN-N3 covers inconsistent dialect or terminology.

Read the complete sentence after substituting a phrase: an article or preposition that suited the old phrase may no longer fit. Check headings and form labels as standalone English as well as in context.

Examples below are editorial examples, not new facts to insert:

| Awkward phrase | Possible revision | Condition |
|---|---|---|
| a teaching prototype | an agent prototype built using a sample case | Only if the programme actually builds an agent on that case. Otherwise ask what is taught. |
| a working AI case | AI used in everyday work / an AI pilot | Choose from the stated meaning; these are different stages. |
| team development | software development / developing the team's skills | Resolve the ambiguity from context. |
| prepare a text | draft a response / write a report | Use the actual deliverable; do not guess it. |
| an cost and benefit estimate | an estimate of costs and benefits | Recheck the article after rewriting. |
| Which function the participants come from | Which teams will participants come from? | A form question; preserve the data it asks for. |

Check vague uses of process, solution, context, environment and implementation. These can be accurate terms; repeated use becomes a problem when the reader cannot identify the thing or action.

## Business offers

Use code EN-O1 for a mismatch between the promise and delivery terms. Preserve distinctions between training and implementation, prototype and production system, included support and optional services, elapsed weeks and contact hours. A recommendation based on analysis is not automatically a tested hypothesis.

Example: source says a two-day course plus an optional strategy day. A rewrite must not call this a three-day course with strategy included. If two source sections disagree, report the disagreement rather than choosing the smoother wording.

Do not silently broaden an audience or reinterpret a form option. A phrase meaning 'agent in production' cannot become 'any AI use' as a grammar-only edit. Explain proposed semantic changes separately.

## Typography and rhythm

Use code EN-T1 for formatting that harms reading. Follow house style for heading case, curly quotes, serial commas and dash spacing. Keep en dashes in ranges such as 6–10 weeks. Preserve punctuation within names, code, URLs and quotations.

Use active voice when it clarifies responsibility. Passive voice is useful when the actor is unknown or irrelevant. Software can calculate a total; there is no universal requirement for a human subject. Keep meaningful adverbs such as separately, approximately and independently.

Vary rhythm when the text is monotonous, without required sentence lengths or deliberate fragments. Three real deliverables remain three. Do not add slang, idioms or opinions to manufacture personality. Existing idioms can stay if they fit the voice and audience.
