# Capability: условия работы в карточке клиента (`.local/web`)

Записано при закрытии C-17 (2026-11-19). Не выложено; серия проверена на поддельном Google.

- S-terms-1: в профиле клиента можно выбрать «Программа» (число сессий, дата начала) или «Разово» либо оставить без условий; после сохранения и перезагрузки условия на месте — test: .local/web/tests/c17-terms.test.ts › save terms
- S-terms-2: в шапке клиента с программой видно «Программа: N из M»; N — записи (встречи) этого клиента в кабинете с датой не раньше начала программы; у «Разово» — «Разово»; без условий строки нет — test: .local/web/tests/c17-terms.test.ts › progress
- S-terms-3: когда в программе осталась одна сессия, в шапке «Осталась последняя сессия»; после последней — «Программа завершена» — test: .local/web/tests/c17-terms.test.ts › program end
- S-terms-4: в профиле можно указать постоянный слот (день недели, время, раз в неделю / раз в 2 недели); он виден в шапке клиента («Вторник, 19:00, каждую неделю») — test: .local/web/tests/c17-terms.test.ts › slot
- S-terms-5: при сохранении слота с подключённым календарём кабинет предлагает «Поставить серию в календарь»: серия создаётся с ближайшего такого дня, на число оставшихся сессий программы (у «Разово» и без программы — без конца); можно отказаться — test: .local/web/tests/c17-terms.test.ts › slot series
- S-terms-6: при выборе слота видно, если в это время уже стоит постоянный слот другого клиента или встреча в календаре, — «Вторник 19:00 уже занят: Марина»; сохранить всё равно можно — test: .local/web/tests/c17-terms.test.ts › slot conflict
- S-terms-7: другой коуч не видит и не меняет чужие условия; без входа закрыто — test: .local/web/tests/c17-terms.test.ts › isolation
- S-terms-8: блок «Условия» и шапка без горизонтальной прокрутки на 1280/390/320 и доступны с клавиатуры — test: .local/web/tests/c17-terms.cjs › layout
- S-terms-9: число N можно поправить руками («Сколько сессий уже прошло?»); после поправки новые записи продолжают прибавляться к поправленному числу, удалённая запись — убавляет; поправка видна после перезагрузки — test: .local/web/tests/c17-terms.test.ts › manual count
