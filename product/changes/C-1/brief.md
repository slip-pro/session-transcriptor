# C-1: Один вход для файлов и короткие действия у клиента

Status: agreed
Agreed: 2026-11-04 — уточнения Сергея к уже принятому UX: «если можно в блок главный добавить поддержку как записей так и готовых транскриптов», «Очень далеко добираться до редактирования заметки», «что за странный функционал добавления нового клиента из карточки существующего клиента?»
Size: small change — переиспользуются текущий импорт JSON, сохранение отдельных полей и клиентская привязка; новые бизнес-правила и получатели данных не добавляются.

Why: добавить материал через один вход и исправить заметку там, где её читаешь; действия учитывают выбранного клиента.
Today: главный блок принимает только аудио; JSON спрятан в других способах; подготовка показывает заметку только для чтения; создание клиента предлагается и у уже связанной сессии.
After: общий выбор/перетаскивание аудио или JSON; редактирование заметки на месте; у связанной сессии имя клиента, история и явная смена привязки без создания нового клиента.
Would fail if: JSON отправляется на ASR; создаётся новая копия заметки вместо изменения источника; обычное сохранение стирает правки другой вкладки; смена клиента меняет подписи DOCX.
Won't do: новые форматы транскриптов, внешние вызовы AI, денежный учёт, публикация, новая визуальная концепция.
Must stay true: импорт не вызывает ASR; авторизация и конфликты сохраняются; документ остаётся первым результатом; встреча без записи доступна.

Scenarios:
- change S-cabinet-1: один выбор файла принимает аудио или готовый JSON, сохраняет выбранного клиента и показывает следующий шаг без повторного выбора файла — test: .local/web/tests/cabinet-ux.test.ts › classify and route supported materials
- change S-cabinet-2: заметка последней встречи редактируется в подготовке и после сохранения совпадает с заметкой исходной сессии; конфликт сохраняет оба варианта — test: .local/web/tests/cabinet-editor.test.ts › a same-field conflict preserves both texts
- change S-cabinet-3: связанная сессия не предлагает создать клиента; явная смена привязки сохраняется и не меняет имена DOCX — test: browser › assigned session binding
