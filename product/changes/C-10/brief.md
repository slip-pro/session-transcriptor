# C-10: Кабинет готов к выпуску (без выкладки)
Status: draft
Request: «давай готовить кабинет к выпуску. но пока не выкладывать» (2026-11-11)
Why: чтобы в любой момент можно было одной командой выложить кабинет и дать паре человек пользоваться им на своих записях. Главная проверка: настоящая запись, загруженная через кабинет, превращается в Word в формате ICF.
Would fail if: кабинет на сервере теряет клиентов, записи или Word после перезапуска; один тестировщик видит записи другого; основной путь «аудио → Word» работает только на подставных ответах; старый сайт transcribe.kiberry.ai ломается или меняется.
Size: feature — серверное хранение личных данных третьих лиц (сессии клиентов), личные аккаунты, внешние сервисы Deepgram и OpenAI/Codex, резервные копии.
Today: кабинет существует только на этом компьютере и не сохранён в git. Настоящую запись целиком он ни разу не обработал (ключа Deepgram в его окружении не было, тесты подставляют ответы). Серверная сборка содержит только старый сайт. У базы кабинета нет постоянного места на сервере и резервных копий. Аккаунты заводятся скриптом вручную. Срок хранения записей не решён.
After:
- Одна настоящая запись прошла через кабинет локально: загрузка → распознавание Deepgram → пунктуация Codex → Word, который открывается и соответствует формату ICF.
- Код кабинета сохранён в git проекта веб-приложения (локальные коммиты; отправка на GitHub — только по отдельному «да»).
- Серверная сборка включает кабинет и обработчик: база, записи и результаты лежат в постоянном каталоге и переживают перезапуск и пересборку. Сборка проверена локально в Docker.
- Готов порядок выкладки и отката: настройки nginx, переменные окружения, команды. Всё описано, но на сервере не применено.
- Аккаунты тестировщиков заводятся одной командой; самостоятельной регистрации нет.
- Ежедневная резервная копия базы и результатов с проверенным восстановлением.
- Срок хранения записей соблюдается автоматически (по решению владельца ниже).
Won't do: выкладка на сервер и любые изменения на transcribe.kiberry.ai; отправка кода на GitHub без отдельного «да»; оплата, квоты и бесплатные 3 расшифровки; самостоятельная регистрация; приглашения по почте; изменения интерфейса кабинета.
Must stay true: старый сайт и его общий пароль работают как сейчас; записи каждого коуча видны только ему; аудио уходит только в Deepgram, текст только в Codex/OpenAI — новых получателей нет; ключи и пароли не попадают в git и в образ.
Decided for you:
- Резервные копии лежат на том же сервере в отдельном закрытом каталоге; копию вне сервера можно добавить позже.
- Для локальной проверки используется ключ Deepgram из корневого .env и вход Codex этого компьютера.
- Пилот рассчитан на пару человек: один обработчик и очередь по одной записи, как на старом сайте.

Open for the owner:
1. Как тестировщики входят в кабинет.
2. Сколько хранить аудио и расшифровки.
3. Какую запись можно отправить в Deepgram и Codex для настоящей проверки.
