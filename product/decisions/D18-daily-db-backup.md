# D18 Ежедневная резервная копия базы кабинета на том же сервере
Дата: 2026-11-12 (C-10), бриф C-10. Обработчик раз в сутки копирует базу (клиенты, встречи, расшифровки, заметки, аккаунты; Word собирается из базы) в отдельный закрытый каталог `/opt/session-transcriptor/backups`, хранит 14 копий. Аудио в копию не входит. Восстановление — `scripts/cabinet-restore.ts` при остановленных web и worker. Копия вне сервера — позже.
