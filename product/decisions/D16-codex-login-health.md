# D16 Обработчик сам проверяет вход Codex
Дата: 2026-11-12 (C-10). Обработчик раз в час, когда свободен, делает крошечный вызов Codex и пишет результат; удачная пунктуация задания тоже считается проверкой. `/api/health` отвечает 503 `codex_login_failed`, если вход не работает. `codex login status` для этого не годится: он показывает «Logged in», даже когда токен отозван. У сервера свой вход (`codex login --device-auth`), копию `auth.json` с другого компьютера не используем. Заменяет: проверку здоровья только по «пульсу» обработчика.
