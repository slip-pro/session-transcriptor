# D24 Google Календарь подключается своим OAuth-модулем, отдельно от входа
Дата: 2026-11-19 (C-13). Владелец: «давай может сделаем авторизацию через гугл? она всё равно нужна. ну и сразу с календарём простая будет интеграция»; порядок — «Calendar first».

Календарь подключается кнопкой «Подключить Google Календарь» через свой небольшой модуль OAuth и Calendar API (`lib/cabinet/calendar.ts`), а не через вход better-auth. Разрешения сразу на список календарей (чтение) и события (чтение и правка — для следующего изменения, правки встреч). Причины: подключение не открывает вход через Google раньше времени, адреса Google подменяются поддельным сервером в тестах, токен хранится зашифрованным. «Войти через Google» позже — через better-auth на том же OAuth-клиенте Google, с отдельным разрешением.
