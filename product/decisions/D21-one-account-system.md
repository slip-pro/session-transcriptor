# D21 Одна система аккаунтов, кабинет по отметке
Дата: 2026-11-18 (C-11), бриф и дизайн C-11. Транскрибатор и кабинет используют одни аккаунты (better-auth). Регистрация открыта для транскрибатора: почта, пароль, согласие на обработку данных (хранится дата), подтверждение почты письмом. Вход в кабинет решает серверная отметка `cabinetAccess`; её ставит только команда приглашения `deploy/cabinet-user.sh` (она отказывает, если почта уже занята). Ссылка из письма подтверждения не входит в аккаунт; сессии, открытые до подтверждения, сбрасываются. Уточняет D19: «регистрации нет» больше не верно для транскрибатора; кабинет по-прежнему по приглашению.
