# D14 Встреча создаётся только из файла; главная — про клиентов в работе
Дата: 2026-11-06 (C-8), владелец: «Встреча без записи, только заметка… оказалась не нужна», «Да, и там убрать». Новую встречу добавляют одним выбором файла — аудио или готовый текст, без выбора типа; создать встречу без файла нельзя ни на главной, ни у клиента, ни в «Все встречи». Старые встречи без записи остаются и открываются. На главной вместо последних встреч — клиенты в работе; «Клиенты» показывают всех, архив ниже. Заменяет: «Встреча без записи — только заметка», «Оставить заметку» в окне «Новая встреча», ссылку «У меня готовый текст», переключатель «В работе / Архив» (C-2, C-3, C-5).
