# D28 Перенос и отмена встречи с гостями уведомляют гостей
Дата: 2026-11-19 (C-14). Владелец: галочка «Отправить приглашение» включена по умолчанию («Да, как рекомендуешь»).

При создании гость добавляется только по галочке (включена по умолчанию, если в контакте клиента есть почта). Перенос и отмена встречи, где есть гости (кроме неё самой и переговорных), идут с уведомлением гостям через Google, как предлагает сам Google; окна переноса и отмены и перетаскивание предупреждают об этом заранее.
